# Learn with Sumit Clone

## Overview

This project is a complete replica of the Learn with Sumit website, built using HTML, CSS, and SCSS. It showcases a pixel-perfect design that is fully responsive, ensuring an optimal viewing experience across a variety of devices.

### Key Features

- **HTML, CSS, and SCSS**: The site is developed entirely with standard web technologies, focusing on clean and semantic HTML markup, along with styled components using CSS and SCSS.
- **Responsive Design**: The layout adjusts seamlessly to different screen sizes, making it user-friendly on both desktop and mobile devices.
- **Pixel-Perfect Accuracy**: Careful attention has been given to replicate the original design with high fidelity, ensuring that every element is positioned and styled precisely.

### Technologies Used

- HTML
- CSS
- SCSS
